What works

Three of four wallpaper types.

Wallpaper Engine ships four kinds. Video and web need nothing extra; scenes use a renderer the picker installs for you.

Video

Built-in renderer (WebKitGTK + GStreamer)

Out of the box

Web

Built-in renderer (WebKitGTK)User properties and audio-reactive data are supported.

Out of the box

Scene

linux-wallpaperengine, patchedMost 2D scenes work, with scripts, text, clicks and media displays. About 1 GB to download, a few minutes to build.

One-click install

Application

Windows executables

Not supported

Scenes with a 3D perspective camera are not supported by the scene renderer yet; the picker marks those it recognises as Not supported.

Scenes that read your player.

A scene’s media display shows what is playing in any MPRIS player: title, artist, position, and the cover when the player hands it over as a local file.

Day to day

Stays out of the way.

Pauses when covered

Playback pauses while every monitor is covered by a maximized or fullscreen window.

Several monitors

Apply a wallpaper to all of them, or to one.

Playlist

Add wallpapers to a playlist and rotate them on a timer.

A still as the system background

A still of the wallpaper is set as the desktop background, and the previous background comes back when you stop.

The picker is available in English and Traditional Chinese and follows the system language.

Install

From Steam to your desktop in four steps.

Needs Ubuntu with GNOME Shell 51 on Wayland, and Wallpaper Engine owned on Steam. Nothing from Wallpaper Engine is bundled.

  1. 1

    Get your wallpapers

    In Steam, enable Steam Play for all other titles and install Wallpaper Engine; it only has to be installed, not run. Then subscribe to wallpapers in the Workshop.

  2. 2

    Install the package

    Download the .deb from the latest release, then:

    $ sudo apt install ./gnome-paper-engine_*_all.deb
  3. 3

    Log out and back in, then enable

    A running GNOME Shell only discovers new extensions at login.

    $ gnome-extensions enable gnome-paper-engine@koukeneko.github.io
  4. 4

    Open Paper Engine

    Find it in the app grid. For scene wallpapers, press Install on the bar above the wallpapers.
