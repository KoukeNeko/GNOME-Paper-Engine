Initial release. Requires GNOME Shell 51 on Wayland (developed on Ubuntu 26.10) and Wallpaper Engine in the Steam library.

## New

🖼️ Live wallpapers. Video, web and scene wallpapers from Wallpaper Engine are rendered as the desktop background, beneath all windows and the desktop icons. A wallpaper can be applied to every monitor or to a single one.

🧭 Picker. The library is grouped by wallpaper type, and each wallpaper's own options (colours, sliders, toggles) are editable in the details pane. The Steam Workshop can be browsed and searched in the same window; subscribing opens the wallpaper's page in the Steam client.

🎬 Scene wallpapers. The scene renderer is installed from the picker. Scene scripts, text layers, click handling and pointer parallax are supported, and puppet-warp characters are drawn.

🎵 Media displays. Scenes with a media display obtain the title, artist, playback position and cover from the active MPRIS player.

🪟 Shell integration. The wallpaper is shown behind the Activities overview, in the workspace thumbnails and on the lock screen. It also replaces the system background used by Blur my Shell.

🧊 Still image as desktop background. A still of the wallpaper is set as the system desktop background and is displayed before the wallpaper starts. The previous background is restored when the wallpaper is stopped.

⏯️ Playback. Playback pauses automatically while every monitor is covered by a maximized or fullscreen window. Pause, mute and stop are available in the picker, and wallpapers in the playlist can rotate at a set interval.

🔊 Audio. Audio-reactive web wallpapers receive the spectrum of the system's audio output.

🌏 Languages. The picker is available in English and Traditional Chinese.

🔒 Security. Each web wallpaper is restricted to the files in its own folder.

## Known limitations

🧱 Scenes that use a 3D perspective camera are not rendered. The picker marks those it can identify as not supported.

🦴 Bone animations are not played; characters are shown in their rest pose. Timeline fade animations are applied at their end state.

💿 The cover in a media display is shown only when the player provides it as a local file.

🛠️ Application wallpapers are Windows executables and are not supported.

## Installation

Download `gnome-paper-engine_0.1.0_all.deb` from the assets below and install it:

```bash
sudo apt install ./gnome-paper-engine_0.1.0_all.deb
```

Log out and log back in, enable the extension once with `gnome-extensions enable gnome-paper-engine@koukeneko.github.io`, then open **Paper Engine** from the app grid.

## 繁體中文

首次發行。需要 Wayland 上的 GNOME Shell 51（於 Ubuntu 26.10 開發），以及 Steam 收藏庫中的 Wallpaper Engine。

## 新功能

🖼️ 動態桌布。Wallpaper Engine 的影片、網頁與場景桌布可作為桌面背景顯示，位於所有視窗與桌面圖示下方。桌布可套用至所有螢幕或單一螢幕。

🧭 選擇器。桌布庫依類型分組，各桌布的選項（顏色、滑桿、開關）可於詳細資訊窗格調整。同一視窗可瀏覽與搜尋 Steam 工作坊；訂閱時於 Steam 用戶端開啟該桌布的頁面。

🎬 場景桌布。場景渲染器可於選擇器內安裝。支援場景指令碼、文字圖層、點擊處理與游標視差，並可繪製 puppet warp 角色。

🎵 媒體顯示。具備媒體顯示的場景，自使用中的 MPRIS 播放器取得歌名、演出者、播放進度與封面。

🪟 Shell 整合。桌布顯示於活動概覽後方、工作區縮圖及鎖定畫面，並取代 Blur my Shell 所使用的系統桌布。

🧊 以靜態畫面作為系統桌布。桌布的靜態畫面將設為系統桌布，於動態桌布啟動前顯示。停止桌布時，即還原先前的系統桌布。

⏯️ 播放。所有螢幕皆被最大化或全螢幕視窗覆蓋時，自動暫停播放。選擇器提供暫停、靜音與停止，播放清單中的桌布可依設定間隔輪播。

🔊 音訊。隨聲音變化的網頁桌布，可取得系統音訊輸出的頻譜。

🌏 語言。選擇器提供英文與繁體中文。

🔒 安全性。各網頁桌布僅可存取其所在資料夾內的檔案。

## 已知限制

🧱 使用 3D 透視攝影機的場景無法顯示。選擇器會將可辨識者標示為不支援。

🦴 不播放骨架動畫，角色以靜止姿勢顯示。時間軸淡入淡出動畫直接套用結束狀態。

💿 媒體顯示的封面，僅於播放器以本機檔案提供時顯示。

🛠️ 應用程式桌布為 Windows 執行檔，不予支援。

## 安裝

自下方附件下載 `gnome-paper-engine_0.1.0_all.deb` 並安裝：

```bash
sudo apt install ./gnome-paper-engine_0.1.0_all.deb
```

登出後重新登入，以 `gnome-extensions enable gnome-paper-engine@koukeneko.github.io` 啟用擴充套件一次，再自應用程式格線開啟 **Paper Engine**。
