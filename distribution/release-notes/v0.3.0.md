## New

⏯️ Playback rules. Playback can continue, mute, pause or stop while another application is focused, a window is maximized or fullscreen, another application plays audio, or the computer runs on battery power. When several rules apply, the strongest action is taken. Stopping ends the renderer and releases its memory.

🖥️ Pause while the screen is shared. An optional setting pauses playback for as long as a screen share or recording is running.

🎚️ Quality. The frame rate limit is adjustable and applies to scene and web wallpapers. Scene wallpapers can be rendered at 75% or 50% of their resolution and without particle effects.

🎮 Graphics card. On computers with more than one graphics card, the card that renders the wallpaper can be selected. If the wallpaper does not appear on the selected card, the setting returns to the system default and a notice is shown.

## Changes

🎞️ Web wallpapers. The default frame rate limit of web wallpapers is reduced from 60 to 30 frames per second.

🎬 Scene renderer. The renderer no longer uses a multisampled window surface, which reduces its video memory use. The new quality settings require the renderer to be rebuilt; the picker offers the rebuild.

🔁 Pause setting. A pause mode set in an earlier version is carried over to the rules for maximized and fullscreen windows.

## Fixes

🛡️ Conflicts with other extensions. Lowering the wallpaper window, returning the focus, pausing and repositioning the window are each abandoned when repeated more than ten times a second, and a warning naming the action is logged. Previously such a conflict could cause continuous flicker.

## Known limitations

🎮 A graphics card that does not drive the display may be unable to present the wallpaper. This is the case for an integrated card on a computer whose display is driven by an NVIDIA card; the setting then returns to the system default.

## Installation

Download `gnome-paper-engine_0.3.0_all.deb` from the assets below and install it:

```bash
sudo apt install ./gnome-paper-engine_0.3.0_all.deb
```

Log out and log back in to load the new version.

## 繁體中文

## 新功能

⏯️ 播放規則。其他應用程式取得焦點、視窗最大化或全螢幕、其他應用程式播放音訊，或電腦使用電池供電時，可分別設定為繼續播放、靜音、暫停或停止。多項規則同時成立時，採用效力最強者。停止將結束渲染器並釋放其記憶體。

🖥️ 螢幕分享時暫停。新增選用設定，於螢幕分享或錄製期間暫停播放。

🎚️ 品質。影格率上限可調整，並適用於場景與網頁桌布。場景桌布可用 75% 或 50% 解析度渲染，亦可關閉粒子效果。

🎮 顯示卡。具備多張顯示卡的電腦，可選擇用於渲染桌布的顯示卡。所選顯示卡未能顯示桌布時，設定即還原為系統預設，並顯示提示。

## 變更

🎞️ 網頁桌布。網頁桌布的預設影格率上限由每秒 60 影格降為 30 影格。

🎬 場景渲染器。渲染器不再使用多重取樣的視窗表面，視訊記憶體用量因而降低。新增的品質設定須重新建置渲染器方可生效，選擇器將提供重新建置。

🔁 暫停設定。先前版本所設定的暫停模式，將沿用至最大化與全螢幕視窗的規則。

## 修正

🛡️ 與其他擴充套件的衝突。降低桌布視窗、交還焦點、暫停及重新定位視窗等動作，每秒重複超過十次即予放棄，並記錄指明該動作的警告。先前此類衝突可能造成持續閃爍。

## 已知限制

🎮 未驅動螢幕的顯示卡可能無法顯示桌布。螢幕由 NVIDIA 顯示卡驅動的電腦上，內建顯示卡即屬此情形；設定屆時將還原為系統預設。

## 安裝

自下方附件下載 `gnome-paper-engine_0.3.0_all.deb` 並安裝：

```bash
sudo apt install ./gnome-paper-engine_0.3.0_all.deb
```

登出後重新登入，以載入新版本。
