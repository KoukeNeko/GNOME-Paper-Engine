## New

🧹 Uninstall script. `uninstall.sh` removes an installation made with `install.sh` from the source folder. With `--all`, it also removes the scene renderer, the downloaded scene assets, SteamCMD with its saved Steam sign-in, and the caches; if the desktop background is the still image of the wallpaper, the background is reset first. When the package is also installed, the script indicates how to remove it.

The package itself is unchanged from 0.3.0.

## Installation

Download `gnome-paper-engine_0.3.1_all.deb` from the assets below and install it:

```bash
sudo apt install ./gnome-paper-engine_0.3.1_all.deb
```

Log out and log back in to load the new version.

## 繁體中文

## 新功能

🧹 解除安裝指令稿。`uninstall.sh` 可移除自原始碼資料夾以 `install.sh` 所安裝的副本。加上 `--all` 時，亦一併移除場景渲染器、已下載的場景素材、SteamCMD 及其所儲存的 Steam 登入資訊與快取；系統桌布若為桌布的靜態畫面，將先予以重設。若系統同時安裝了套件，指令稿將說明其移除方式。

套件內容與 0.3.0 相同。

## 安裝

自下方附件下載 `gnome-paper-engine_0.3.1_all.deb` 並安裝：

```bash
sudo apt install ./gnome-paper-engine_0.3.1_all.deb
```

登出後重新登入，以載入新版本。
