## New

📦 Scene assets without Wallpaper Engine installed. The picker can download the scene assets with SteamCMD, so Wallpaper Engine no longer has to be installed through Steam Play. The download signs in to Steam, and the account must own Wallpaper Engine.

👤 Steam account. The settings show the account that SteamCMD stays signed in as and provide a sign-out, which removes the saved sign-in and keeps the downloaded assets.

🔄 Update notice. When a newer version is installed while the picker is open, the picker shows a notice with a restart button, so that the new version is loaded.

## Changes

🌫️ Blur my Shell. When Blur my Shell is installed, its blur of the Dock and the top bar includes the windows behind them by default. The setting is applied once; a later change made by the user is kept.

⏯️ Playback. Playback is no longer paused while a workspace or a workspace thumbnail is showing the wallpaper, as in the overview and the app grid.

## Fixes

🖥️ Screen sharing. Backgrounds blurred by Blur my Shell continue to follow the wallpaper while the screen is being recorded or shared. Previously the wallpaper behind the overview stopped as soon as a screen share started.

## Installation

Download `gnome-paper-engine_0.2.0_all.deb` from the assets below and install it:

```bash
sudo apt install ./gnome-paper-engine_0.2.0_all.deb
```

Log out and log back in to load the new version.

## 繁體中文

## 新功能

📦 無須安裝 Wallpaper Engine 即可取得場景素材。選擇器可透過 SteamCMD 下載場景素材，不再需要以 Steam Play 安裝 Wallpaper Engine。下載時須登入 Steam，且該帳號須擁有 Wallpaper Engine。

👤 Steam 帳號。設定中顯示 SteamCMD 所保留登入的帳號，並提供登出；登出將移除已儲存的登入資訊，已下載的素材則予以保留。

🔄 更新提示。選擇器開啟期間若安裝了較新的版本，選擇器將顯示提示與重新啟動按鈕，以載入新版本。

## 變更

🌫️ Blur my Shell。已安裝 Blur my Shell 時，其 Dock 與頂端列的模糊預設包含後方的視窗。此設定僅套用一次，使用者其後所作的變更將予以保留。

⏯️ 播放。工作區或工作區縮圖正在顯示桌布時（如活動概覽與應用程式格線），不再暫停播放。

## 修正

🖥️ 螢幕分享。螢幕錄製或分享期間，經 Blur my Shell 模糊的背景仍持續跟隨桌布更新。先前只要開始分享螢幕，活動概覽後方的桌布即告停止。

## 安裝

自下方附件下載 `gnome-paper-engine_0.2.0_all.deb` 並安裝：

```bash
sudo apt install ./gnome-paper-engine_0.2.0_all.deb
```

登出後重新登入，以載入新版本。
